## Message architecture (shared across all scripts)

Canonical one-liner (from `docs/visibility-playbook.md`):

> UnClick is the universal remote for AI: one MCP install that gives any compatible agent 450+ callable endpoints across 60+ integrations, plus persistent cross-session memory.

Homepage pillars (from `src/pages/Index.tsx`): every tool, memory that remembers, signed permissions, built-in proof the work was done right. One install.

Highlight checklist each script draws from:

1. One npm/MCP install. No config sprawl.
2. 450+ callable endpoints across 60+ integrations (email, Slack, Stripe, Shopify, GitHub, weather, maps, AI models, security lookups, and a long tail).
3. Four meta-tools (search, browse, tool info, call) keep the agent's tool list tiny. Everything else is discovered at runtime.
4. New tools ship server-side. The agent picks them up automatically. No package update.
5. Persistent cross-session memory: identity, standing rules, durable facts, session summaries, recall.
6. Memory follows you across Claude, ChatGPT, Cursor, any MCP client. Your context belongs to you, not the vendor.
7. Signed permissions: you control what the agent can touch.
8. Built-in proof: QA receipts (XPass) that the work was done right, not just claimed.
9. Dogfooding: UnClick is substantially built by AI agents using UnClick, coordinating on its own Boardroom job board, with QA gates checking work before merge.
10. Honest posture: public connector depth ladder, free tier (100 tool calls/day), build-in-public.

Public naming only: do not reference internal-only product names in produced videos.

## Production notes

- Every script closes on the same canonical line or tagline so cross-platform repetition compounds ("universal remote for AI" / "Stop clicking. Start asking.").
- Scripts 1, 2, 5, 7 are built for vertical short-form (TikTok, Reels, Shorts). Scripts 3, 6, 9, 10 suit YouTube pre-roll and X/LinkedIn native. Scripts 4 and 8 work in both once cut to 60s.
- All demo beats must be real screen captures per the honesty posture. No mocked UI.
- Numbers to keep in sync at production time: endpoint count (450+), integration count (60+), free-tier limit (100 calls/day). Verify against the site before final render.
